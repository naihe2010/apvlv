Read apvlv like a Vim buffer.

apvlv is a PDF, DJVU, EPUB, HTML, TXT, FB2, and CZW viewer with Vim-like behavior. This guide converts the man page into browsable sections for the web.

synopsis apvlv [options] [file]
01 Key commands

Open files, move pages, scroll, search, zoom, mark, and quit.

 02 Configuration

Set window size, zoom, engines, notes, OCR language, and more.

 03 Prompt commands

Use colon commands for opening files, tabs, splits, printing, and jumps.

Options

Start exactly where you want.

-c file

Load configuration from file instead of ~/.apvlvrc.

-h

Show the help message and exit.

-v

Show the version and exit.
