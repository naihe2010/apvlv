Manual Commands Settings Prompt

Keyboard map

Commands that keep your hands on the keys.

Commands can be prefixed by a number where a count is meaningful. Unless noted otherwise, the default count is 1.

Open and tabs

Files, folders, tabs.

o

Display a file chooser to open a PDF, DJVU, EPUB, HTML, or TXT file.

O

Select a directory to display.

t

Open a PDF, DJVU, EPUB, HTML, or TXT file in a new tab.

T

Select a directory to display in a new tab.

R

Reload the current file.

gt

Show the next tab.

gT

Show the previous tab.

Movement

Pages and scroll.

G

Show page number count.

PageDown

Go forward count pages. Also C-f.

PageUp

Go backward count pages. Also C-b.

C-d

Go forward count half pages.

C-u

Go backward count half pages.

H

Scroll to page head.

M

Scroll to page middle.

L

Scroll to page bottom.

s

Skip count pages.

k

Scroll up count units. Also C-p or Up.

j

Scroll down count units. Also C-n or Down.

h

Scroll left count units. Also Backspace or Left.

l

Scroll right count units. Also Space or Right.

Document tools

Search, zoom, marks.

r

Rotate the document clockwise by 90 degrees.

/ string

Search forwards for string.

? string

Search backwards for string.

f

Toggle between fullscreen and window mode.

zi

Zoom in.

zo

Zoom out.

zw

Zoom to fit window width.

zh

Zoom to fit window height.

m char

Mark the current position to char.

' char

Return to the mark position char.

''

Return to the last position.

c

Toggle directory display.

q

Close the current window.

ZZ

Quit the viewer with ZZ, like Vim.
