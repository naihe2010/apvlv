Vim-style reading for real documents

apvlv

A keyboard-first viewer for PDF, EPUB, TXT, FB2, MOBI, CBZ, HTML, and more. Navigate pages, tabs, directories, and annotations with the rhythm of Vim.

Download View source
GPL licensed Qt6 Linux and Windows
Vim keys Use familiar commands such as j, k, h, l, Ctrl-f, and Ctrl-b.
Many formats Read PDF, EPUB, TXT, FB2, MOBI, CBZ, HTML, images, and more.
Directory flow Browse folders like document outlines and open files in tabs.

Designed for readers who stay on the keyboard

Build from source

Qt6, CMake, and a straight path to install.

apvlv builds with CMake and uses Qt6 plus Quazip, with optional engines such as Poppler, MuPDF, and Tesseract for richer document support. 

cmake -B build -S .
cmake --build build
cmake --install build
